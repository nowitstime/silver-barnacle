# Card values (forked tests)

At every pick, the run was copied once per card offered and each copy played on 30 turns with the same luck. **Value** = how many more rows that copy got than the average of its offer (alive copies also score for a safe board). Positive means the card beat the other options it was offered with. 953 card samples from 306 picks. Generated by `npm run balance -- cardvalue`.
