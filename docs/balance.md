## Notes

- Each seed is shared across classes by run index, so with 3 runs per class the class numbers are mostly seed luck. Use `RUNS=50` before trusting them.
- Runs are bimodal: they either die around depth 30–60, or snowball past the fifth boss into the 220-turn cap. Late-game ball counts (150–200) outgrow brick HP. The next tuning pass should make the late curve steeper or slow ball growth.
- After this report, Bomber's Payload explosion was halved (level × 0.3), since it jumped from a median of 61 to the cap.
